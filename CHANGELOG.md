# Change Case Companion Changelog

## [Unreleased]

## [0.1.0]

### Added

- Convert to camelCase, PascalCase, snake_case, kebab-case, and
  CONSTANT_CASE -- works starting from any of the 5 styles, correctly
  handling acronym runs (`XMLHttpRequest` -> `XML`/`Http`/`Request`).
- Works on Editor text directly, not PSI -- any file type, not just
  Java/Kotlin.
- No selection required -- expands from the caret to the nearest word.
